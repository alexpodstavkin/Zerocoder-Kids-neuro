# mk-school-ai — лендинг мастер-класса «Создай своего ИИ-репетитора»

Боевая версия с https://sites.zerocoder.ru/mk-school-ai/ на 10.09.2026.
Статика: HTML + CSS + JS. Сборка не нужна — положить папку на хостинг, открыть `index.html`.

## Состав
- `index.html` — вся разметка + скрипт катящегося дедлайна (в `<head>`) + Яндекс Метрика 72085663.
- `styles.css` — стили сайта. Брейкпоинты: 1359 / 1023 / 639 / 374.
- `site.js` — монтирование двух инлайн-форм GetCourse (первый экран и секция «Запись»).
- `kit/base.css`, `kit/core.js` — общий стартер лендингов Зерокодера.
- `assets/` — картинки (WebP/PNG/SVG).

## Форма GetCourse
- Виджет `id=1654375`, uid `2aa7fd2f999cf641ba1dffd2b2af092fb02fda03`.
- В `index.html` встречается в 3 местах: две формы (`data-gc-uid` / `data-gc-src`) и строка `<link rel="preload">` в `<head>`. Менять виджет — во всех трёх.
- Форма отдаётся GC в iframe — стили полей и кнопки меняются только в настройках виджета в GetCourse.

## Дедлайн «Приём заявок»
Меняется сам: до 15-го числа — «15 <месяц>», после — «30 <месяц>» (в феврале — последний день), переключение в полночь МСК.
Хардкодить дату нельзя — только `<span class="js-deadline">`. Проверить любой день: `index.html?now=2026-09-16T00:01`.

## При правках
Меняешь `styles.css` / `site.js` — подними `?v=` в `index.html`, иначе браузеры покажут старую версию из кеша.
