# project-state — zerocoder-tg-bot-leadform

**Обновлён:** 2026-09-22
**Бренд:** Зерокодер
**Тип продукта:** бесплатный вводный урок (демо-урок 1-на-1 по нейросетям)
**Флаг проекта:** ЭКСПЕРИМЕНТ — нестандартный формат (страница-имитация Telegram-бота), не по шаблону лендинга
**Маршрут:** R0 — полный пайплайн

## Задача владельца
Лендинг, оформленный как экран Telegram-бота: шапка бота, фон-паттерн Telegram,
поверх — карточка лид-формы в стиле конструктора лид-форм VK Ads
(баннер-обложка, заголовок, буллиты, поля, зелёная кнопка), внизу — синяя кнопка «Начать».

## Решения на входе
- Механика: СТАТИЧНАЯ карточка как на референсе (не диалог с ботом)
- Приём лидов: виджет GetCourse (компонент GetCourseWidget, как на боевых лендах kids.zerocoder.ru)
- Референс: assets/reference-vk-leadform.png
- Фон Telegram: assets/tg-pattern-green.jpg (зелёный паттерн — совпадает с брендовым зелёным Зерокодера)

## Состав экрана (редакция 3, после правок владельца)

Шапка бота (`components/BotHeader.tsx`) → полотно чата с тёмным паттерном (`app/page.tsx`) → карточка (`components/LeadCard.tsx`).
Внутри карточки: баннер (`components/CardBanner.tsx`) → плашка бренда → заголовок → абзац → строка-возражение → форма (`components/GetCourseWidget.tsx`) → зелёная кнопка.
Все тексты — `app/content.ts`. Цели Метрики — `components/track.ts`. Прокрутка к форме — `components/scrollToForm.ts`.

Удалено владельцем: нижняя синяя кнопка «Начать» (`StartBar.tsx`), реплика бота в фоновом пузыре (`BotBubble.tsx`), подпись баннера, три буллита.

## Техника (проверено в браузере 2026-09-22)

- Next.js 16 + Tailwind 3.4, `output: 'export'`, basePath `/tg-bot-urok`. `npm run build` проходит.
- Виджет GetCourse влезает в карточку 330 px без масштабирования: iframe 306 px. Имя, телефон, эл. почта, два чекбокса согласий — видны целиком.
- Высота формы: виджет свою высоту сообщением не присылает, работает фолбэк 640 px. На 470 px текст согласия обрезался посреди строки. **При замене на свой ID виджета высоту перемерить.**
- Прокрутка к форме: собственный твин на rAF со страховкой. Штатные средства в этой конструкции не работают — `scrollIntoView` давал 12 px вместо 486, CSS `scroll-behavior: smooth` глушил `scrollTo`, `scrollTo({behavior:'smooth'})` не двигал контейнер. Записано комментариями в коде.
- Признак прокрутки — маска-растворение нижнего края тела карточки. На полосу прокрутки полагаться нельзя: в macOS и iOS она overlay и в кадре не появляется.
- Контраст кнопки: тёмный текст на `#00E48D` (10.96:1). Белый на `#00C159` давал 2.39:1 и проваливал AA, на ховере — 1.68:1.
- На экранах до 480 px карточка занимает весь экран (медиазапрос). Проверено правилом, скриншотом не снято: окно браузера в автоматизации не ужимается ниже 1280.

## Закрыто во второй волне правок

- Виджет GetCourse — воронка 1623916 (ленд neyroseti-otkrytyy-urok). В форме есть поле «Возраст ребенка» и выбор «Родитель», телефон без флага США.
- Высота формы берётся из сообщения виджета (557 px), а не из фолбэка. Слушатель чинился дважды: сверка источника сообщения отбрасывала всё, а ранний выход по флагу снимал слушатель в режиме разработки.
- Зелёная кнопка пропадает при доезде до формы и возвращается при прокрутке вверх. Проверка учитывает высоту формы: пока виджет не отрисовался или если он заблокирован, кнопка остаётся на месте.
- Фон: паттерн кладётся плиткой 800×450 один к одному вместо растягивания, сверху мягкая виньетка слоем фона.
- Прогон по 320/360/375/390/430 — см. `tools/README.md`. На 320 px убран средний значок шапки, иначе обрезалось слово «урок».
