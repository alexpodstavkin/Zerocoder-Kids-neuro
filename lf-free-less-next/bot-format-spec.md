# Спецификация формата «страница-бот» (разбор референса)

**Источник:** `assets/reference-vk-leadform.png` — конструктор лид-форм VK, открытый внутри Telegram-бота.
**Задача:** повторить анатомию 1-в-1, наполнить Зерокодером.

---

## Анатомия экрана (сверху вниз)

### 1. Шапка бота (белая полоса, ~56px)
- Слева: иконка «назад» ‹ (серая, декоративная, не кликается)
- Круглый аватар бота 36–40px: логотип Зерокодера (оранжево-красный круг с молнией у референса → у нас зелёный/брендовый круг с лого)
- Две строки: **название бота** (bold, 15px, тёмный) + `Бот` (13px, серый)
- Тень/бордер снизу — hairline

### 2. Фон-полотно
- Паттерн Telegram: `assets/tg-pattern-green.jpg` (728×410, зелёный доодл-паттерн)
- Поверх — брендовый зелёный градиент-тинт, чтобы фон попал в палитру Зерокодера
- Занимает всё пространство между шапкой и нижней кнопкой

### 3. Фоновая реплика бота (декор, частично скрыта карточкой)
- Белый пузырь чата справа-по-центру, радиус ~14px, лёгкая тень
- Круглый аватар бота внутри/сверху + 2–3 строки текста
- Карточка перекрывает его слева — ровно как на референсе. Это создаёт ощущение «карточка открыта поверх диалога»

### 4. Карточка лид-формы (главный объект)
- Ширина ~330px desktop, центр экрана; на мобиле — почти во всю ширину с полями 12px
- Белая, радиус верха ~12px, сильная тень
- **Хедер карточки** (~48px): ✕ слева, **центрованный bold-заголовок**, справа ⋮ и ⤢ (декоративные)
- **Тело карточки — скроллится внутри себя**, видимая тонкая полоса скролла справа
- **Кнопка внизу карточки — sticky**, всегда видна поверх скролла

#### Содержимое тела (порядок с референса)
1. **Баннер-обложка** — edge-to-edge, соотношение ~16:9. У референса — готовый рекламный креатив с заголовком. У нас: свёрстанный брендовый баннер (не картинка-заглушка), плюс слот под детское фото.
2. **Плашка сообщества** — узкая капсула со скруглением, мелкий серый текст в 2 строки: название + слоган. Справа от неё — круглый логотип-аватар, приподнятый над плашкой.
3. **H1 карточки** — КАПСОМ, bold, 3 строки максимум, тёмный
4. **Блок смысла** — серый текст 14px: строка-контекст + нумерованный список 2–4 пункта
5. **Абзац «почему это работает»** — серый, 4–6 строк
6. **Подводка к списку** («На бесплатных занятиях:») + список
7. **Форма** — виджет GetCourse
8. **Sticky-кнопка** «Записаться» — зелёная (брендовый #00E48D / #00C159), радиус 8px, во всю ширину карточки минус поля

### 5. Нижняя кнопка «Начать» (во всю ширину экрана)
- Синяя Telegram (#3390EC / #2AABEE), белый bold-текст по центру, радиус ~8px
- Отступы по 12px от краёв, фиксирована у низа экрана
- По клику — скроллит к форме внутри карточки (единственное реальное действие)

## Технические решения
- **Стек:** Next.js 16 + Tailwind 3.4, `output: 'export'` — как у боевых лендов репо `Zerocoder-Kids-neuro`
- **Форма:** компонент `GetCourseWidget.tsx` — брать зрелую версию из `ai-kruzhok-next/components/GetCourseWidget.tsx` (там уже закрыт баг качающейся высоты: высота берётся только от своего iframe по `e.source`, пишется в `--gc-h`, применяется через CSS `!important`). ID виджета — заглушка + TODO владельцу.
- **Габариты:** карточка ~330px — это узко для виджета GetCourse. Поля виджета должны влезать без горизонтального скролла и БЕЗ масштабирования (`transform: scale` запрещён — правка владельца 11.09.2026).
- **Скролл:** тело карточки — `overflow-y: auto` с кастомной тонкой полосой; страница целиком НЕ скроллится (фиксированная высота `100dvh`), иначе иллюзия Telegram рассыпается.
- **Мобилка:** шапка + карточка на всю высоту, нижняя кнопка на `env(safe-area-inset-bottom)`.
- **Счётчики:** Яндекс.Метрика 72085663 + Top.Mail.Ru/VK 3739769.
- **Шрифт:** Manrope (канон Зерокодера). Системный шрифт Telegram НЕ имитируем — только в шапке допустима нейтральная подача.

## Что НЕ делаем
- Диалог с ботом, «печатает…», пошаговый квиз — владелец выбрал статичную карточку.
- Скролл всей страницы как у обычного лендинга.
- Масштабирование формы через transform.
