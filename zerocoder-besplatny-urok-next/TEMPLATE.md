# Шаблон лендинга Зерокодер (Next.js + Tailwind)

Единый каркас лендинга бренда **Зерокодер** для трафика. Дизайн воссоздан **1-в-1** по живому аудиту 8 боевых лендингов zerocoder.ru (подработка, антикризис, вайб-кодер, родители, claude-code, deepseek, грант, нейросети детям). Берётся как старт для нового проекта — меняешь акцент и контент, дизайн уже задан системой.

## Дизайн-ДНК (зашит в шаблон)
- **Шрифт:** Manrope (300–800) — на всех живых лендах. Fira Sans — для акцентного курсива (`.accent-italic`).
- **Типографика:** заголовки H1/H2 — вес 700, **плотный трекинг −0.03em**, UPPERCASE (по канону). Body 16px, line-height **1.55**. H3 — 700, без капса.
- **Радиусы:** карточки 12/15/20px, hero/фичи 28px, пилюли 100px, мелкие теги 5px, flat-кнопки 10px.
- **Тени:** по умолчанию плоско. `shadow-soft` / `.card-float` — мягкая тень с оттенком акцента (как «парящие» карточки на гранте). `.glow-acc` — свечение-акцент.
- **Фоны секций:** белый ↔ `paper`/`soft` (светлый тинт акцента) ↔ `dark`. Чередуй для ритма.
- **Фото:** скругление углов в px (компонент `<Photo>`), кадрирование cover, опц. поворот-стикер (`rotate`). Кругов на фото бренд не использует.
- **Иконки:** Uicons by Flaticon (rounded). Лежат в `/public/uicons`. Атрибуция в подвале (free-план).
- **Автомасштаб** как в Tilda: zoom от 1280px, 0.70–1.40, off ≤860 (`AutoScale`).

## Как сменить акцент (главное!)
Акцент — единственное, что меняется под проект. Правишь **4 строки** в `app/globals.css` → `:root`:
```css
--acc: #00e48d;       /* основной */
--acc-dark: #00c159;  /* hover */
--acc-soft: #eaf7ee;  /* пастельный тинт */
--acc-2: #00b36f;     /* конец градиента */
```
Готовые пресеты со всех живых лендов — внизу `globals.css` (зелёный, фиолетовый, оранжевый, красный-огонь, лайм, коралл/Anthropic, индиго). Скопируй нужный блок. Дефолт — **зелёный** (цвет логотипа = ядро бренда).

> Подбор акцента: нет дефолта-клетки — бери цвет под тему/аудиторию/оффер. 1 доминирующий акцент, максимум 2 цвета + нейтрали. Текст на лайме/светлых акцентах — тёмный `#141413`.

## Компоненты (`components/`)
| Компонент | Назначение |
|---|---|
| `Header` | sticky-шапка с blur, лого + навигация + CTA |
| `Hero` | первый экран: pill, H1 с выделением, lead-карточка, CTA, фото |
| `Section` / `SectionHead` | обёртка секции (фоны white/paper/warm/soft/dark) + заголовок (без eyebrow) |
| `Bento` / `Cell` | бенто-сетка 2/3/4 кол.; ячейки plain/paper/accent/dark, span, иконка |
| `Stats` / `StatCard` | крупные цифры акцентом (на тёмной секции) |
| `GiftBand` | блок подарков (акцентный тинт + иконки-чипы) |
| `Speaker` | спикер: фото + регалии с точками |
| `LogoStrip` | полоса логотипов СМИ/партнёров |
| `Faq` | аккордеон на `<details>` |
| `FinalCta` | финальная тёмная градиентная панель |
| `Photo` | фото с cover-кадрированием, скруглением px, поворотом |
| `Button` | кнопки: primary (pill) / flat / ghost / dark |
| `Icon` / `IconChip` | иконки Uicons |
| `Reveal` | появление blur-fade на скролле |
| `AutoScale` | автомасштаб zoom |
| `Footer` | подвал с реквизитами Зерокодера (менять не нужно) |

## Как сделать новый лендинг
1. Скопировать папку в `~/Desktop/Афина/projects/<имя-проекта>/`.
2. В `package.json` поменять `name` и порт (`dev`/`start`).
3. Выбрать акцент: скопировать пресет в `globals.css` → `:root`.
4. В `app/page.tsx`: оставить нужные блоки, заменить тексты. Набор блоков по типу продукта — см. `~/.claude/memory/zerocoder-landing-structures.md`.
5. Подставить реальные фото в `<Photo src="..." />` и `<Hero photoSrc="..." />`.
6. Иконки подбирать из `~/.claude/skills/athena/assets/uicons/icon-names.txt` (грепом), передавать имя в `<Icon name="..." />` / `<Cell icon="..." />`.
7. `npm install` → `npm run build` → `npm run start`.

## Правило перезапуска (важно)
Чтобы не словить рассинхрон CSS-хэшей (stale-сервер отдаёт старый HTML → слетают стили):
```
lsof -ti tcp:5240 | xargs kill -9 ; rm -rf .next ; npm run build ; npm run start
```
