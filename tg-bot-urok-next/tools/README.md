# Инструменты проекта

## sizes-preview.html — прогон по мобильным размерам

Страница открывает лендинг в пяти iframe с реальными размерами экранов
(320×568, 360×640, 375×667, 390×844, 430×932) и показывает их рядом.
Каждый iframe — собственный вьюпорт, поэтому медиазапросы срабатывают
по-настоящему; окно браузера при этом ужимать не нужно (в автоматизации
оно не сжимается ниже 1280 px).

Как пользоваться:

```bash
cp tools/sizes-preview.html public/_sizes.html
npm run dev
# открыть http://localhost:3000/_sizes.html
rm public/_sizes.html   # обязательно убрать перед сборкой в бой
```

Файл лежит вне `public/`, чтобы не попасть в статический экспорт.
